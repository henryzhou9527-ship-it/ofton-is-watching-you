# お布団巻き is watching you

## Register

product

## Users

An individual checking their own device activity on desktop or Android, with optional visitors if they choose to share their site. Others can deploy their own copy. This is a personal website, not a hosted multi-user service. Each deployer connects their own backend. The distributed source has no preset owner, account, device or remote API.

## Product Purpose

Show what the configured devices are doing now and make existing activity history readable. Keep the current reporting, authentication, database and privacy rules. Statistics use existing activity data in the frontend. Feishu is the only deployment provider used here. The site name is お布団巻き is watching you; the display nickname is separate and configurable. No registration or multi-user backend is in scope.

## Brand Personality

Personal, nocturnal, mischievous. The user explicitly chose お布団巻き as the character theme and DECO*27's Monitoring featuring Hatsune Miku as the music-video visual reference. Use her silver hair, dark glasses, blue eyes and quiet night atmosphere with Monitoring's close wide-angle framing, watching eyes, punchy typography and vivid graphic accents. The configurable nickname identifies the person whose devices are displayed; the character is a visual theme.

## Character Reference

Preserve the cat-ear cap, blue fish armband, silver-gray jacket, zipped black high collar, glasses and silver braids. Character references and theme-art attribution are documented in ASSETS.md; original reference sheets are not included in the public repository.

## Anti-references

Generic SaaS cards; bland anime wallpaper behind a dashboard; explanatory text under every heading; AI-sounding slogans and invented terminology; gratuitous new backend features. Do not infer sleep, work or productivity from being offline. Daily totals and hourly activity count the union of active device intervals: simultaneous devices occupy time only once. Never add device durations to obtain elapsed use time.

## Design Principles

1. Current state is visible immediately, including distinct offline and unavailable states and last report time.
2. Art and motion carry personality; interface words stay short and literal.
3. Daily app ranking, time-of-day distribution and chronological sessions come from existing records.
4. Validate changes in the local preview before publishing. Keep existing collectors and ingestion APIs compatible.
5. Keep the character-led design distinctive and consistent across views.
6. Keep deployment instructions, tutorials and source links in repository documentation rather than on the website.
7. The website is browse-only. The owner sets the site nickname in the paired Android client using their configured server and device credential. Store it on the server and show the same nickname to visitors. No browser-local nickname override or editing form. Tracked defaults remain neutral; never include a personal endpoint, hosting app ID or nickname in source releases.
8. Iterate locally, validate the complete experience, then publish a coherent version when authorized. Do not publish each intermediate design draft.
9. No decorative English signature, software count badge, outgoing reference links or footer navigation. Use an animated pie chart for app usage, and keep the original playful activity text prominent.
10. Add about ten randomly appearing Q-version Juan easter eggs at discoverable click points. They must be brief, nonblocking, optional through the effects toggle, and nonrepeating within a round. Do not add a visible achievement counter or instructions panel.
11. Preserve the large display typography. Improve the small copy with a softer screen-readable face, larger sizes and clearer contrast.
12. Remove ornamental numbers, taglines and small labels from the hero and portrait. Keep the site title, nickname, actual status and playful app activity descriptions; no numbered introductions or decorative signal readouts.

13. Avoid a long scrolling website. Use full-height current/today scenes with a blink transition, separate statistics/detail panels, and fitted replay pagination. Preserve reading size, existing art, filters, deduplicated calculations, browser navigation and reduced-motion support.

## Accessibility & Inclusion

Readable Chinese labels, keyboard-accessible controls, descriptive chart values, non-color status labels, mobile layout, reduced-motion support and an explicit effects toggle. No automatic audio. These are implementation defaults for this preview.
